# 🎡 SPIN PRO · Universal Lucky Wheel

Aplikasi Web Roda Putar Undian (Lucky Spin Wheel) responsif modern bertema Bento & Liquid Glass, zero-emoji vector styling, sintesis Web Audio API tanpa file eksternal, dan perayaan kemenangan interaktif.

## ✨ Fitur Unggulan
- **Universal & Serbaguna**:
  - Preset cepat: Peserta Undian, Keputusan (Ya/Tidak), Doorprize/Hadiah, Angka 1-10, Pilihan Makan Siang.
  - Impor Massal (Bulk Input): Tempel nama sekaligus (per baris atau koma).
  - Tambah, hapus, dan atur segmen roda secara dinamis.
  - Acak urutan (Shuffle) dan Urutkan (A-Z).
- **Fisika & Audio Realistis**:
  - Smooth cubic ease-out deceleration physics.
  - Penunjuk jarum mekanik dengan efek lenting/defleksi spring.
  - Sintesis suara mekanik (ticking) & fanfar kemenangan harmonik berbasis Web Audio API murni.
  - Perayaan konfeti dinamis saat pemenang terpilih.
- **Pengaturan Fleksibel**:
  - Auto-Eliminasi Pemenang (opsi menghapus otomatis nama yang sudah menang).
  - Pilihan durasi putaran: Cepat (3s), Sedang (5s), Dramatis (8s), Tegang (12s).
  - Riwayat pemenang lengkap dengan waktu dan tombol salin clipboard.
  - Mode Gelap / Terang (Dark/Light Mode).
  - Layar Penuh (Fullscreen) & tombol pintas Spasi (Spacebar).
- **Desain Modern (Zero Emoji)**:
  - 100% menggunakan ikon vektor SVG presisi.
  - Tipografi Google Fonts: *Outfit* & *Plus Jakarta Sans*.
